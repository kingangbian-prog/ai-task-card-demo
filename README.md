# 随行 AI · 双屏任务卡 Demo

[在线体验](https://kingangbian-prog.github.io/ai-task-card-demo/)

面向折叠电脑内外屏的 AI 任务卡交互原型。外屏支持多任务列表、逐张切换、新任务下发、暂停与继续；内屏同步展示任务详情，并可收起为桌面卡片。

## 使用

访问在线演示，或下载并直接打开 `index.html`。点击外屏右上角“＋ 新任务”创建任务；使用底部“推进一步”或“自动演示”体验执行流程。

## 原型范围

AI 执行、语音输入与成果均为模拟数据，未连接真实模型或硬件。各任务独立保留本次页面内的状态；刷新会恢复预置任务。自动演示仅推进当前任务，切换任务会停止自动演示。
